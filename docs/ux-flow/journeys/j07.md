## 4. Clarity Issues

- "Low stock" means three things: stock at zero (dashboard, bell, Reports strip), under reorder level (Inventory, Inventory Report), and nothing queued (Shortbook). Pick one definition (under reorder level, which includes zero) and use it everywhere. Measured.
- "Overdue Invoices" counts only status OVERDUE; the part-paid ₹1,450 is also owed but is not overdue. The owner's word is "who owes me"; the screen's word is "overdue". "Pending Payments 0" on Reports reads as unpaid money but means unreconciled payments.
- Dashboard writes "₹2360.00", the rest of the app writes "₹2,360.00" (`app/dashboard/page.tsx:69` uses `toFixed(2)`). Measured.
- "Daily Collection" (sidebar) and "Pharmacy Report" (sidebar) lead to the same workspace; the report is clinic plus pharmacy, so "Pharmacy Report / Accounting Reports" as the breadcrumb on the owner's money screen is misleading (`02-daily-collection.png`).
- Two "Payment Mode Breakdown" sections on Reports use a 30-day default and different numbers from Daily Collection.
- "Clinic received" versus "Clinic billed today" differ whenever old bills are settled; no label says why.
- The notification rows for overdue invoices link to pharmacy Sales (`header.tsx:200`), but the overdue invoice is a clinic bill.

## 7. Verdict

**Convoluted.** The owner's three questions take 3 clicks, two scrolls and two different areas (Daily Collection, Inventory), and the result is incomplete: the landing page answers none of the three in numbers or names, the overdue debtor is never named, and the stock count is 1, 4 or 0 depending on which screen is open. Ideal is 0 clicks; actual is 3 plus the unreachable debtor name. Daily Collection itself is a good screen (defaults to today, one click, internally consistent); the problem is that it is not the landing page and that the dashboard's alert card shows less than the data it already receives.

Honesty notes: figures marked measured come from the fresh-seed run (`output/ux-journeys/j07-check/j07/`) and from reads on the shared stack (Reports, Inventory Report, name searches). The 1 count in the bell on a fresh seed is suspected (read as 2 on a mutated shared stack, same query as the dashboard); the legacy `?tab=low-stock` bell link landing was not walked. Aditya Bhosale's invoice would show on the 8 Nov appointment row (suspected; not walked, as a deep route no owner would take).
